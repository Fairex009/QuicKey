# QuicKey v0.2.3 visual design and color semantics

Visual-only update to v0.2.2 on the same app / keyboard bundle IDs, with no additional iPhone slot or signing entitlement.

Colors are functional, and labels remain present:
- Role / selected role: **blue**
- GitHub PR: **teal**
- GitHub Issue: **amber**
- Flow templates (FAST+DEEP, modes): **violet**
- Primary "Start new chat" / "Insert": **solid deep green**
- Saved prompt paste / Recent: **lavender**
- Clear history / remove prompt: **soft red**
- Navigation + numeric keys: neutral; selected tab with blue shade

The palette uses explicit light/dark variants and high-contrast foreground colors. Active selections have a stronger background, stroke and accessibility selected trait. No color is the only indicator of meaning. System dynamic colors are preserved for neutral controls.

Scope excludes changing prompt generation, persistence, permissions, or timing. No app group or Full Access. The existing 3-app free limit and seven-day certificate expiration remain unchanged.

Device acceptance requires iPhone 13 with both light and dark appearance: review button contrast, legibility, selected states, accessibility text scale and thumb targets. Reconfirm exact CM1 startup, mixed PR/Issue handling and Recent history in-place, then approve PR #1 for merge/release.
