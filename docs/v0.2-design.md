# QuicKey v0.2: FAIREX command keyboard

Source of command vocabulary: private FAIREX repository \`systems/HELP.md\` and \`systems/README.md\` (read 2026-11-22). The private operational state, Issue contents, secrets and long-lived roles are **not** duplicated into this public repository.

## Free app slots
- IPAForge is a desktop app on Ubuntu, not an iPhone app.
- SideStore is one iPhone app, QuicKey is a second. A QuicKey update installed over the **same signed bundle ID** should not consume another active-app slot.
- Two distinct App IDs are used for the host and keyboard extension, but those are not two active-app slots.
- Source identifiers intentionally remain \`org.quickey.prototype\` and \`org.quickey.prototype.keyboard\`; SideStore may append a team suffix at signing. Use the same signing route/team for in-place replacement.
- Ordinary free Apple provisioning still expires after **7 days**. Device refresh remains a separate acceptance test.

## v0.2 scope
- Quick tab: one-tap **exact Human-requested** \`all.in.one ON\\ncmd.nonstop ON\\n\\ncmd.deep:\\ngit.handle \` prefix; plus Deep, Batch ON, Handle PR/Issue prefixes, Refresh.
- Roles tab: actual five registered FAIREX role-entry commands.
- Build tab: choose role, PR/Issue, Direct/Deep/Fast+Deep, enter a positive integer using the keyboard's own number pad, preview complete command, insert only after a valid target.
- Controls tab: read-only Help/Refresh and non-authoritative session controls, plus split task prefix.
- No sensitive actions (no \`cmd.go\`, no protected-effect, no publication button) and no automatic Submit/Send.
- No app-group-sharing, accounts, cloud access, keyboard Full Access or editable persistent snippets. Those are separate v0.3 design work.

## Acceptance
1. GitHub macOS runner verifies exact command templates and rejects malformed numbers.
2. Xcode successfully builds the host and \`.appex\`; IPA preserved both bundle IDs and RequestsOpenAccess=false.
3. Physical iPhone: update existing QuicKey rather than install a duplicate, and ensure existing keyboard remains selectable.
4. Tap Quick > FAST+DEEP in Notes or ChatGPT; see exact four-line template.
5. Build > ENG > PR > Fast+Deep > 160 > Insert; verify exactly:
   \`\`\`text
   res.eng

   all.in.one ON
   cmd.nonstop ON

   cmd.deep:
   git.handle PR #160
   \`\`\`
6. Test globe/Next key, Delete and target number erase.
7. Re-signing within seven days preserves existing installation; confirm on device.

## Boundaries
The keyboard is a local text generator. \`cmd.deep\` and \`git.handle\` take effect only if the user manually submits the message to an appropriate live FAIREX Chat/Work role with all required authority. The public QuicKey repository never becomes authoritative for private FAIREX command semantics.
